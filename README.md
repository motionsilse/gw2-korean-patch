# 길드워2 한글 패치

안녕하세요. Drugged Cat 입니다.

길드워2를 한국어로 즐길 수 있도록 제작한 유저 한글 패치입니다.

최신 버전은 [Releases](https://github.com/motionsilse/gw2-korean-patch/releases)에서 받을 수 있습니다.

## 추천 설정

- 길드워2 입문자: 모든 번역을 켜거나, 아이템 이름 번역만 끄는 설정 추천
- 기존 플레이어 또는 영문 위키를 자주 사용하는 플레이어: 모든 번역을 켠 뒤 고유명사 번역만 끄는 설정 추천
- 그 밖에는 취향에 맞게 자유롭게 설정할 수 있습니다.

길드워2는 오랫동안 서비스된 게임이라 번역해야 할 문구가 매우 많습니다. 최대한 많은 내용을 번역했지만 아직 번역되지 않은 문구가 나타날 수 있습니다.

사용자 DB 수집을 켜면 게임 중 발견한 미번역 영어 문구를 수집합니다. 

자동번역은 백그라운드에서 작동으로 번역하여 1-2초뒤 화면에 반영되며, 잠깐 깜빡일수 있습니다.

기존 사용자 DB는 한글 패치가 업그레이드 되거나 다시 설치를 하는 경우에도 `Guild Wars 2\korean` 폴더를 삭제하지 않는 한 다음 버전에서도 계속 사용할 수 있습니다.

## 고유명사 번역의 한계

고유명사 번역을 켜거나 꺼도 일부 문구에는 설정이 정확하게 적용되지 않을 수 있습니다. 

첫째, 내장DB에 없어서, 사용자DB로 수집된 경우 고유명사를 구분할 수 없습니다.

둘째, 게임에서 같은 영어 단어가 여러 의미로 사용되거나, 문구에 색상이나 특수한 표시가 포함되는 경우가 있기 때문입니다. 

셋째, 방대한 양의 DB라서 카테고리 구분을 잘못했을 수 있습니다.

최대한 구분하려고 시도했으나 완벽하지는 않다는 점 양해 부탁드립니다.

## 업데이트

한글 패치는 계속 개선되고 있습니다. 번역 추가, 오역 교정, 표현 통일과 안정성 개선이 꾸준히 이루어집니다.

만약 길드워2를 업데이트중에 다운로드 속도가 0으로 줄어들어서 패치가 진행되지 않는 상황이 발생한다면

업데이트하기 전에는 한글 패치를 해제하는 것을 권장합니다. 

게임 업데이트가 끝난 뒤 다시 한글 패치를 적용하면 됩니다.



문제가 발생하면 패처에서 모든 항목을 해제한 뒤 적용하여 한글 패치를 제거할 수 있습니다.

## 안내

이 패치는 비공식 사용자 제작 패치입니다. 사용 중 발생할 수 있는 문제를 확인하고 동의하는 경우에만 사용해 주세요.
